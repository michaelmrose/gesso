** Selected read and delivery contract

For a concrete selected GET: establish route ownership; capture canonical
parameters and parse progression; bind the server-observed completed
frontier; fix the selected read clock; resolve the instance; evaluate the
compiled scope policy; perform the authorized query and render through the
checked canonical response boundary. This is not a promise that arbitrary
application code uses that context correctly.

For selected SSE: perform the shared context preparation; optionally check
current session validity; resolve the scope and require model authority.
Admit interest and capacity using the existing transport lifecycle.
Before each invalidation or keepalive handoff repeat the selected
authorization using the original request and a fresh completed frontier
observation. Compare the result with the originally admitted topic/id.
Account for active policy callbacks in the existing bounded pending
authorization ledger, even when stream cancellation races them.

A false or throwing frame policy publishes a sticky refusal before the
asynchronous producer continuation. Refusal and local put initiation are
ordered under a per-stream fence. Provider evaluation and asynchronous
put completion do not hold that fence. Termination retires the admitted
stream and its interest; callback accounting is separate from stream
retirement.

A database membership revocation, an observed policy refusal, a local
stream put, an actual network transmission and a browser adoption are
different events. In particular, v2468 does not establish that no byte can
arrive after a database revocation. Previously initiated puts cannot
be recalled. Do not use this evidence to certify that property.

** Temporal and authentication assumptions

- Browser progression is a minimum read requirement, not a credential.
  The selected database frontier must satisfy the existing same-database
  requirement; a stale browser carrier cannot select an older authority
  snapshot. The ordinary Biff snapshot token and wrapped Graph snapshot
  boundary are installed by the existing frontier binder. Progression-aware
  queries apply canonical progression after ordinary query options.
- The selected valid-time clock is fixed across context-aware ordinary and
  planned reads. The binder preserves an admitted trusted current-time
  value where one exists, otherwise samples server time. A reused trusted
  clock is not necessarily a fresh wall-clock sample at each frame.
  Explicit SQL temporal expressions and raw provider access are outside
  the claimed correspondence. This is a selected-database contract,
  not cross-database atomicity or universal bitemporal isolation.
- No immutable empty snapshot is asserted. The XTDB probe in v2471
  demonstrated a nil time coordinate in the empty snapshot token.
  v2472 refuses selected reads without a completed frontier. The current
  empty-path response statuses are GET 400 and SSE 403. Initialization
  belongs to the application/deployment; general Biff startup and
  provider-neutral standalone handlers retain their earlier contracts.
- The optional session predicate is an SSE configuration hook, not an
  authentication implementation or a corresponding GET configuration
  option. GET must receive trusted authenticated context from its host
  and enforce current authority through the applicable policy. Scope
  authorization does not itself authenticate a principal, and public
  scopes intentionally omit private scope authorization. Session registry,
  expiry, reassignment and identity extraction are application obligations.
- Policies must consult the appropriate current authority. Model callbacks
  can still ignore the supplied context. Route capture, session authority,
  scope policy and endpoint access are independent requirements, not proofs
  of arbitrary application-defined resolver or policy equivalence.
- Reauthorization at the next frame is not immediate revocation while
  idle; disabling keepalives may leave a silent connection until another
  frame or cleanup. Authorization-capacity exhaustion refuses a frame.
  Costs of repeated policy evaluation have not been load-qualified.
